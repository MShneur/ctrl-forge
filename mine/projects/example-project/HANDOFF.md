This is what a handoff looks like. When an AI (or you) stops working, this file
is what the next session reads first. It answers three questions:

## Done
- Set up the example project so a newcomer can see the shape of one.

## Pick up first

- Then: `python tools/new_project.py "Your Real Project"`
